# Policy Test

[ADR-0402](../../docs/adr/0402-policy-test-scope-and-verification.md) の Policy 層である。本リポジトリの ADR を読まなければ書けない invariant だけを持つ（同 決定1-3）。`make tf-policy` が実行し、`make tf-policy-canary` がその検査自体を検査する（[`.makefiles/terraform/policy.mk`](../../.makefiles/terraform/policy.mk)）。

## 入力

各 `usecases/<use-case>/reference/tests/policy-input.tftest.hcl` を mock provider で plan し、`terraform test -json -verbose` が出す `test_plan` から `provider_schemas` を除いたものである（同 決定11）。すべての reference の root がこのファイルを持たなければ、`make tf-policy` は落ちる。

除いた `provider_schemas` からは、型ごとの書ける非推奨の引数（属性と block）の一覧を取り出し、`data.provider_schema.deprecated_arguments` として2つ目の `--data` で渡す（同 決定18）。宣言は root に依らず1つなので、一覧は reference の root をまたいだ和である。`test_plan` の `provider_format_version` が宣言と違えば、取り出す前に落ちる。

policy の文書が参照する ARN は、`override_resource`（`override_during = plan`）で instance ごとに与える。与えないと文書が plan で unknown になり、`[PLAN-INPUT-04]` で落ちる。

`inline_arguments` に宣言した文字列の属性は、同じ `override_resource` で `null` を与える。mock provider は書いていない computed な属性に乱数を入れ、そのままでは `[PLAN-INPUT-09]` で落ちる。override は書いた値を隠さない。`aws_s3_bucket` の `policy` について、`make tf-policy-canary` がこれを固定する。

`env/` の root は `make tf-policy` の入力にしない。資格情報なしでは plan できないためである。CI の plan と apply の経路（`.makefiles/terraform/operation/ci.mk` の `CI_PLAN` と `CI_APPLY`）は、実 provider の plan の `terraform show -json` に `plan.stateful_protection`・`plan.kms_key_policy`・`plan.resource_policy_exclusive` だけを掛ける（target ごとの `CI_POLICY_NAMESPACES`）。ほかの package は mock の入力を前提にしているので、実 plan には掛けない。CI は `plan.input` を掛けないので、Key Policy が無いことと読めないことは `plan.kms_key_policy` 自身が落とす（`PLAN-KMS-00`・`09`）

入力は `tmp/tf-policy/` に書かれる。mock の値だけを含む。`make tf-policy` も CI の `tf-policy` job も、これを artifact や Pull Request のコメントへ出さない。

## Policy を足すとき

- `<name>.rego` と `<name>_test.rego` を同じディレクトリに置く。規則は `deny contains` で書き、違反の ID（`[PLAN-<区分>-<番号>]`）を持たせる。テストは `test_violation_` と `test_pass_` で始まる名前の両方を持ち、各 ID をどこかのテストが名指しする（名指しの有無までを見る。違反側のテストが名指すかは見ない）。どれかが欠けると `make tf-policy` が落ちる（同 決定8・9）
- 見る resource の型と address は `decl.json` に足す
- 名前空間の一覧は宣言しない。`make tf-policy` は、このディレクトリのすべての `.rego` の package ごとの行頭の `deny contains` の数を、conftest が名前空間ごとに評価した規則の数と突き合わせる（`tf-local policy-result -policy`）。規則を足せば突き合わせの対象に入る。字下げした規則や文字列の中の規則の行は、件数が合わずに落ちる。`deny contains` を持たない `.rego` は `lib/` の下にだけ置ける
- Security の道具（[ADR-0501](../../docs/adr/0501-development-tooling-composition.md) 決定6）の既定のルールと重ならないことを、本リポジトリの書き方の文書で確かめる（ADR-0402 決定3）。確かめた結果は Pull Request に書く
