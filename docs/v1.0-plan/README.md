# v1.0 の計画

> **このディレクトリは v1.0 到達時に消える。** 恒久的な文書を置く場所ではない。

ここにあるのは、v1.0 で何を実装し何を実装しないかを決めるための計画文書である。実装が進むにつれて、内容は所有者のいる文書へ移っていく。移り終えたとき、ここには何も残らない。

## なぜ消えるのか

ADR-0701 決定2 が文書の所有を割り当てている。その表に「要件定義書」は無い。ここにある記述は、それぞれ次の所有者を持つ。

| ここにある記述 | 最終的な所有者 |
| --- | --- |
| ユースケースの責務境界・supported / unsupported | `modules/<use-case>/README.md`（ADR-0102 決定2） |
| 設計判断とその根拠 | ADR（配置は ADR-0001 に従う） |
| 未決の論点 | 判断 Issue、決まったら ADR |
| 検討の経緯 | git（ADR-0701 決定3） |

## 参照してよい範囲

- **Issue と Pull Request からは参照してよい。** どちらも暫定の作業記録であり、閉じれば役目を終える。
- **リポジトリに残るものからは参照しない。** `modules/<use-case>/README.md`、ADR、`.tf`、コードコメントからここへリンクしないこと。参照したくなったなら、その内容は参照先の文書が所有すべきものである。

この区別を守らないと、このディレクトリを消したときに、残った文書のリンクが一斉に切れる。

## 正本

**このディレクトリのファイルが正本である。** 計画を練る下書きがリポジトリの外にあってもよいが、根拠として参照してよいのはここにあるものだけとする。外で固めた内容は、Pull Request としてここへ入れる。
